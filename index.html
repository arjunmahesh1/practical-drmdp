WHAT IS BEING SHOWN

Saved results, inspectable sources

The unit is a trained policy

Each point averages policy-level evaluation returns. A policy-level return first averages that policy’s evaluation episodes. The shaded band shows one sample standard deviation across trained policies. It is not a confidence interval and does not treat episodes as independent training seeds.

No invented severities

The slider snaps to the exact deployment values in the saved evaluation. Connecting lines help read the curves; they do not represent additional measurements. Nominal conditions are marked separately. A larger numeric value need not mean a harder task.

Controls stay distinct

The ordinary standard policy is always the bold blue curve. Inactive TV caps, physical ensembles, and context controls keep their own labels. We never choose the worst available reference. Environment versions and separate policy cohorts are not pooled.

Playback and paper statistics

A saved episode return does not contain a trajectory. Where a checkpoint replay is available, the environment view names its training seed, episode seed and parameter. It is a separate illustrative rollout from a saved policy. The paper curve always uses the original saved evaluation returns.

Failures remain missing

Failed training runs receive no invented evaluation return. The measured policy count is shown for each point. Walker SAC–KL β50 has 29 measured policies; Lunar SAC–KL β10 has 26. These curves are conditional on available final policies.

Exploration is not confirmation

Selecting the best-looking cap after viewing a curve is descriptive exploration. These plots alone do not establish a fixed setting’s suite-wide robustness, task success, or improved reliability.

Source manifest

Only completed local summary tables were exported. No active cluster jobs were read or modified.
